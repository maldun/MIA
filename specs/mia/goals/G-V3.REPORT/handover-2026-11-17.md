## Pitfalls met in this goal (keep)
- A long run started in the background (`&`) makes `test_shutdown*` fail (the process ignores SIGINT): run in the foreground. Never run browser tests while another run goes.
- `pgrep -f "unittest discover"` matches its own shell: check the log's last line, not the process list.
- `podman images | head` cut the list: `localhost/mia-browser` existed. Check with `podman image exists`.
- A change of a shared escape needs the whole unit suite, not the neighbours (F-8: `defang` rewrote `http://` too).
- Protected files are built as patches in a sandbox copy of the repo (`git archive HEAD | tar -x`, edit, `git diff`), checked with `git apply --check` and installed by the owner.
