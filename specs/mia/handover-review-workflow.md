- **The review became a literature review in fixed stages (A-18, owner design):** keywords from the question (user may replace them) -> one search per keyword -> collect (de-duplicate, keywords per work, cut-off and retraction drop list) -> abstract screening -> **checkpoint** (the user must agree before the full texts) -> full-text screening (open access only, section by section) -> keyword extension (terms in at least 3 screened works, searched only after approval) -> **summary** -> report. Design and sources: `specs/mia/eval-drafts/review-design.md`. REQ-WFM-018 to -020 reworded, REQ-WFM-027 (keyword extension) and -028 (staged screening) are new and still `Draft`.
- **Two independent judgements per work (owner's rule):** relevance grade 0 to 3 and eligibility include / maybe / exclude with a reason code (`off_topic`, `outdated`, `wrong_type`, `language`). Code never derives one from the other. A quote that is not in the source downgrades a judgement to `maybe` (`unverified_quote`); a section whose quote is not in its text does not count for the grade.
